The Voter ID enrollment project began in a handful of Karnataka assembly constituencies during the 2023 state elections — and quickly spread, expanding across multiple Indian locations in collaboration with NGOs and community organisations.

## Scale

Between **November 2023 and March 2024**, partners ran **500+ camps**, processing more than **30,000 voter ID applications**. ABF trained **100+ local volunteers** to handle the paperwork independently, so the model could continue running without our presence.

## Coalition

This project was carried out in collaboration with **Reclaim Constitution, Lifeline Foundation, Project Smile Trust, Milli Council KA, WISH Foundation, We Care Charitable Trust, Zuha Trust, Masjid One Movement, and Beyond Boundaries Foundation**. ABF is grateful to every partner who collaborated.

## Why this is "a people's movement"

This wasn't ABF doing voter enrollment. It was ABF helping a network of organisations and citizens **become** the system. Every volunteer trained was one more node that could run a camp without instructions from us.

That's the model we keep returning to.
